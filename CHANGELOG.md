# Changelog

All notable changes to this project are documented in this file, one entry
per release. Format loosely follows [Keep a
Changelog](https://keepachangelog.com/en/1.0.0/); entries are kept high-level
(what shipped, breaking changes) rather than a full commit-by-commit log --
see git history for that.

Differences from PyPI `pyside6-qtads` are listed under **Breaking**, with the
details in [docs/compatibility.md](docs/compatibility.md).

## [Unreleased]

### Breaking

- `ads.CFloatingDockContainer.waylandMoveOrLeaveInWindowPreview` takes a 4th,
  required `Floatable` argument, compared with `pyside6-qtads` 5.1.1.1. This
  comes from QtAds itself (upstream #873, after 5.1.1), not from the binding.

### Added

- QtAds built from
  [borco/Qt-Advanced-Docking-System](https://github.com/borco/Qt-Advanced-Docking-System)
  (`extern/qtads`, branch `qtads-py/edba03d0`, upstream `master` after 5.1.1)
  as a shared library, bundled in the wheel, against PySide6 6.12, for
  Python 3.11 to 3.15 (#1, #3).
- The full `pyside6-qtads` API (#2): every class, enum, method and signal it
  binds, under the same names and in the same shapes, with the same
  module-level names, so that `import pyside6_qtads_borco as QtAds` is a
  drop-in change. Checked by running its tests unmodified and by an API
  superset test against a snapshot of `pyside6-qtads` 5.1.1.1.
- Type stubs (`_pyside6_qtads_borco.pyi`), generated by `tools/generate_pyi.py`.
- Wheels for Windows x86_64, Linux x86_64/aarch64 and macOS arm64/x86_64
  (#3). The Linux wheels use the system's libxcb and libxkbcommon.
